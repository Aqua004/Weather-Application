# Weather Forecast Project

A simple weather forecast web page built with HTML, CSS, and JavaScript.

## Features
- Search for a city
- View current weather details
- Display a simple forecast layout

## How to run
1. Open `weather-forecast.html` in your browser.
2. Or serve the folder using a simple local server if needed.

## Project files
- `weather-forecast.html` - main page
- `Web tech ppt.pptx` - presentation file
