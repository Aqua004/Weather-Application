# 🌦️ Weather Forecast Web Application

A modern, responsive weather forecasting web application built with **HTML, CSS, and JavaScript**. The application provides real-time weather information and a 5-day forecast using the **Open-Meteo Forecast API** and **Geocoding API**. Users can search weather conditions for any city or automatically retrieve weather based on their current location.

---

## 📌 Features

- 🌍 Search weather by city name
- 📍 Automatic weather detection using browser geolocation
- 🌡️ Real-time temperature and "Feels Like" temperature
- 💧 Humidity and precipitation information
- 💨 Wind speed and wind direction
- 👀 Visibility details
- 🌅 Sunrise and sunset timings
- 📅 5-Day weather forecast
- 📱 Fully responsive user interface
- ⚠️ Error handling for invalid city names and network issues

---
